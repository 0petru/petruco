## Google Sheets Audit Submissions

The audit forms submit to `/api/audit`, which forwards the data to a Google Apps Script webhook.

1. Create or open a Google Sheet and open **Extensions > Apps Script**.
2. Copy the code from [`google-apps-script/Code.gs`](google-apps-script/Code.gs) into the Apps Script editor.
3. Deploy it as a **Web app**, choose **Anyone** as the access setting, and copy the deployment URL.
4. Create `.env.local` from [`.env.example`](.env.example) and set `GOOGLE_SHEETS_WEBHOOK_URL` to that URL.
5. Restart the Next.js server after changing the environment variable.

The script creates an `Audituri` sheet automatically and appends a row for each submitted audit.
